# Production files

Always derived from `../algebra-a-signature-master.svg`. Never redrawn by hand, never by AI.

- `embroidery/`: digitized files (DST / EMB) made by the embroiderer **from the master SVG**, one per size.
  Minimum A width 25 mm (≈ 18 mm high). If the "=" does not read on a sample, increase the size, never change the geometry.
  Thread colours: ivory on black and navy, ink on ivory, tonal (black on black, navy on navy); knit to confirm on a sample.
- `print/`: chest print files (DTG / DTF / screen) exported from the master at the size and resolution the producer specifies.

Waiting for the producer's specifications (file format, resolution, colour profile, maximum area, minimum line).
Back prints of the Graphic Series are not here: see `design/print-master/`.
