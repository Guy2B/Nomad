# Graphic Series · Capsule 01 "Physics in Ink"

Direction set by the owner on 22.10.2026 (9 reference photos + 4 boards in Downloads): ink sketch, graffiti hand lettering,
real equations and construction marks on the back; one small sign on the chest; heavy boxy tee; colourways from the brand palette.
Replaces the first concept (Delta 01 / Sigma 02 / Infinity 03, archived in `capsule/_archive/`).

## Files

`npm run capsule` (scripts/physics.mjs) writes, for each design in `capsule/<id>/`:

| File | Use | Size |
|---|---|---|
| `back-light.svg` / `.png` | back print for Ivory, Sage, Taupe | 300 × 400 mm, PNG 3543 × 4724 px (300 dpi), transparent |
| `back-dark.svg` / `.png` | back print for Black, Deep Navy, Burgundy | same |
| `front-light.svg` / `.png`, `front-dark.svg` / `.png` | chest icon, left chest | 70 × 70 mm, PNG 827 × 827 px |

Mockups (flat garments, flagged MOCKUP): `npm run mockups` → `site/assets/mockups/`.
Ink sets: light garments navy #131A2B + blue #2E5AA8 + burgundy #6A2232; dark garments ivory #EDE6D6 + blue #7097DA + gold #C9A86A.
Print technique (DTG or DTF), maximum area and colour count at A61: **TO VERIFY** (docs/SUPPLIERS.md, open point 10).
