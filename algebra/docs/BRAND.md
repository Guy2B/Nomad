# Brand system

**Name**: Algebra (capital A only; ALGEBRA only as an exceptional graphic use).
**Signature**: *Built on proportion.* Chosen over "Essentials, solved." because it describes the product (cut, proportion, balance)
and works for both the essentials and the Graphic Series. One signature only, kept in English in all three languages, like the wordmark.

## Logo architecture

| Level | File | Use |
|---|---|---|
| Primary symbol | `brand/symbol.svg` | A in high-contrast serif: hairline left stem, heavy right stem. Its crossbar is doubled by a second bar of equal weight that runs through the heavy stem: the "=" lives inside the letter, not beside it. |
| Embroidery symbol | `brand/symbol-embroidery.svg` | Same, with thicker bars and hairline (6.4 / 5.2 / 6.8 units) so it holds at 12–20 mm. One colour. Digitizing at A61: 33 € net. |
| Wordmark | `brand/wordmark.svg` | "Algebra" in Cormorant Garamond SemiBold, converted to outlines, light positive tracking. |
| Italic wordmark | `brand/wordmark-italic.svg` | Editorial variant (campaigns, labels). |
| Lockup | `brand/lockup-horizontal.svg` | Symbol + wordmark (site header). |
| Favicon | `brand/favicon.svg` | Ivory symbol on navy. |
Generated by `npm run brand` (scripts/brand.mjs) so every file stays consistent. Fonts: SIL Open Font License.

## Product branding hierarchy
- Polos: small embroidered symbol, left chest, about 18 mm.
- Essential tees: small embroidered symbol (about 14–16 mm).
- Sweaters: symbol tone on tone.
- Graphic Series: large back drawing, small chest icon. Never a billboard on the essentials.
